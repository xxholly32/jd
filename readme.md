## AI Agent 实战项目

### chat-anything (内部 AI Agent 桌面客户端)

**项目背景**：针对公司内部非研发人员使用 Claude Code 门槛高、且受限于网络环境无法使用外部工具的痛点，独立开发了基于 React + Electron 的 AI Agent 桌面客户端，并深度对接公司 MaaS 平台。

**核心贡献与业务价值**：
- **能力封装与落地**：将公司内部 SaaS 平台 API 抽象并封装为可被 Agent 调用的 Skills，成功落地 2 个实际业务项目（含某全国 500 强企业级项目），将 AI 能力无缝嵌入业务场景。
- **全栈 Agent 体验**：完整实现了多模型灵活切换、Skills 插件市场、MCP 工具调用、本地文件预览与 `@` 智能引用等现代 Agent 交互功能。
- **工程可行性验证**：在公司内部获得广泛好评，充分验证了 Agent 产品在复杂企业内网环境与 ToB 场景下的工程落地可行性。
- **行业洞察**：深刻理解国内 ToB Agent 落地的核心痛点（内网隔离、私有化部署成本高、交付链路长），并在实践中积累了针对性的应对策略。
